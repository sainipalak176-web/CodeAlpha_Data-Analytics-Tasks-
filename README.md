📌 About the Project

This project explores Netflix's content library (Movies and TV Shows) to uncover patterns in content type, genres, release trends, ratings, and runtime, using Python-based data analysis and visualization techniques.

📂 Dataset

titles.csv — contains details of Netflix titles (id, title, type, release_year, runtime, genres, production_countries, imdb_score, tmdb_score, etc.)

credits.csv — contains cast and crew information linked to each title

Source: Kaggle (Netflix TV Shows and Movies dataset)

🛠️ Tools & Libraries Used:

Python 3

Pandas — data cleaning and manipulation

Matplotlib & Seaborn — data visualization

Google Colab — development environment

✅ Task 2: Exploratory Data Analysis (EDA)

Explored dataset structure, columns, and data types

Checked for missing values and data quality issues

Asked meaningful questions about the dataset (e.g., Movies vs Shows split, genre popularity, rating trends)

Identified key trends and patterns in the data before moving to visualization

✅ Task 3: Data Visualization

Created the following visualizations to turn raw data into clear, meaningful insights:

Movies vs Shows on Netflix (Bar Chart) — Compares total count of Movies and Shows.

Top 10 Genres on Netflix (Bar Chart) — Shows the most common genres across the platform.

Netflix Titles Released Per Year (Line Chart) — Tracks how Netflix's content library has grown over time.

Distribution of IMDb Scores (Histogram) — Shows the spread of IMDb ratings across all titles.

IMDb Score: Movies vs Shows (Box Plot) — Compares rating distribution between Movies and Shows.

Runtime vs IMDb Score (Scatter Plot) — Explores the relationship between runtime and rating, split by content type.

📊 Key Insights

Netflix's catalog is movie-heavy, with significantly more Movies than Shows.

Drama and Comedy are the most common genres on the platform.

Content additions grew slowly until 2015, then spiked sharply between 2015–2020.

Most titles have IMDb scores between 6 and 8, indicating generally decent-to-good content quality.

Shows tend to have slightly higher median IMDb ratings than Movies.

Runtime does not show a strong direct relationship with IMDb score, but Shows and Movies occupy clearly different runtime ranges.
